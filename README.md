# To-do-list
# СРО 2: Алгоритмы и структуры данных

## Задание 1: Список задач (To-Do List)
В данном проекте реализовано консольное приложение на языке Python для управления списком задач. Приложение позволяет добавлять, просматривать и удалять задачи.

### Контрольные вопросы:

1. **Какие операции можно выполнять со списком?**
   В языке Python со списками можно выполнять следующие основные операции:
   * **Добавление:** `append()` (в конец), `insert()` (в определенную позицию), `extend()` (расширение другим списком).
   * **Удаление:** `remove()` (по значению), `pop()` (по индексу), `clear()` (очистка всего списка).
   * **Доступ и поиск:** обращение по индексу `list[i]`, поиск индекса `index()`, подсчет вхождений `count()`.
   * **Трансформация:** `sort()` (сортировка), `reverse()` (разворот), копирование и получение срезов (slices).

2. **Как реализовать удаление элемента по значению?**
   Для этого используется встроенный метод `.remove(value)`. Он находит в списке первый элемент, значение которого совпадает с переданным аргументом, и удаляет его. Если элемент с таким значением не найден, программа выдаст ошибку `ValueError`.

3. **Что происходит при изменении списка во время выполнения программы?**
   Список в Python является динамическим массивом. При добавлении элементов, если текущая выделенная память заканчивается, интерпретатор выделяет новый, более крупный блок памяти и копирует туда старые данные. При удалении элементов происходит сдвиг всех последующих элементов влево, чтобы заполнить пустое место. Важно помнить, что изменение списка (удаление или добавление) непосредственно во время итерации по нему (в цикле `for`) может привести к пропуску элементов или ошибкам логики.
